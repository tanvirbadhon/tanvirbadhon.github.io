# Personal portfolio

A responsive static portfolio inspired by the supplied Rifat Rudro reference: navy background, pink and mint accents, code hero, experience, skills, education, projects, and contact.

## Customize

Edit `dist/content.js` to replace the sample name, title, bio, experience, skills, education, projects, email, and social links. All qualifications and projects are placeholders until replaced. Add a photo and resume to `dist/assets/` and set their paths in the same file.

The contact form opens the visitor's email app when an email is configured. It does not use a backend or claim messages were sent. Unconfigured resume and social buttons explain what needs to be added.

## Preview

Run `node server.cjs`, then open http://localhost:4173. No build or package installation is required. Deploy the contents of `dist/` to a static hosting provider.
